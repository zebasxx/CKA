# CKA Training Path

This learning path progresses from building a Kubernetes cluster to solving
exam-style scenarios under time pressure.

## [1. Cluster Installation](<01-Cluster Installation>)

Build a Kubernetes cluster from scratch using `kubeadm`.

## [2. Cluster Administration](<02-Cluster Administration>)

- Role-based access control (RBAC)
- Certificates
- Control plane and worker nodes
- etcd
- Cluster upgrades

## [3. Workloads and Scheduling](<03-Workloads and Scheduling>)

- Scheduling
- ConfigMaps and Secrets
- Autoscaling
- Workload controllers

## [4. Networking](<04-Networking>)

- DNS
- Services
- Container Network Interface (CNI)
- NetworkPolicies
- Ingress
- Gateway API

## [5. Storage](<05-Storage>)

- PersistentVolumes (PV)
- PersistentVolumeClaims (PVC)
- StorageClasses
- Storage troubleshooting

## [6. Troubleshooting](<06-Troubleshooting>)

Practice diagnosing broken cluster scenarios and recovering services.

## [7. CKA Simulations](<07-CKA Simulations>)

- Timed exercises
- Multiple kubeconfig contexts
- Exam-style tasks
